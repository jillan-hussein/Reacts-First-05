# 🛍️ E-Commerce Website

A modern, responsive **E-Commerce Website** built with **HTML, CSS, JavaScript, and Bootstrap/Tailwind CSS**.
The project provides a clean shopping experience with attractive product cards, categories, cart functionality, and a responsive design.

---

## 🎨 Design & Color Palette

The project uses a modern and elegant color scheme:

| Color        | Purpose             |
| ------------ | ------------------- |
| 🟣 `#6C63FF` | Primary / Buttons   |
| 🔵 `#4F46E5` | Hover / Links       |
| 🩷 `#F43F5E` | Offers / Favorites  |
| 🟢 `#10B981` | Success / Discounts |
| ⚪ `#F8FAFC` | Background          |
| ⚫ `#1E293B` | Text                |
| 🌫️ `#E2E8F0` | Borders / Cards     |

The overall style focuses on **clean layouts, soft colors, rounded cards, and smooth hover effects**.

## 🎯 UI Style

The interface follows a modern e-commerce design with:

- Rounded corners
- Soft shadows
- Clean typography
- Minimal borders
- Responsive grids
- Smooth transitions
- Interactive buttons
- Product hover animations

Example button style:

```css
.btn-primary {
  background-color: #6c63ff;
  color: #ffffff;
  border: none;
  border-radius: 10px;
  padding: 10px 20px;
  transition: 0.3s ease;
}

.btn-primary:hover {
  background-color: #4f46e5;
  transform: translateY(-2px);
}
```

Example product card:

```css
.product-card {
  background: #ffffff;
  border-radius: 16px;
  padding: 15px;
  box-shadow: 0 4px 15px rgba(15, 23, 42, 0.08);
  transition: 0.3s ease;
}

.product-card:hover {
  transform: translateY(-5px);
  box-shadow: 0 10px 25px rgba(15, 23, 42, 0.15);
}
```
